Objetivo: Creador de niveles simple
Mundo almacena y administra las cosas jugables
La UI siempre sera la misma
El Tilemap es el mismo, pero cambia el mapa a jugar
Las unidades cambian segun el nivel


La idea es que al cargar un nivel, este cargue todos esos recursos necesarios para 
funcionar de forma automatica

El nodo TileMap actuara como el contenedor del nivel. Ahi es donde se definira el nivel.
Mundo cargara el nivel que se le asigne. Si no se le asigna o hay error, que cargue uno default.


El nodo TIleMap es un node2d sin funcionalidades mas alla que contener el resto. Puedo usar este nodo
para hacer diferentes mapas reutilizando los nodos tile_map_base y tile_map_hud

TileMap podria tener una carpeta de Unidades donde insertar las unidades. De esa forma, a la hora
de diseñar un nivel se diseña junto a la disposicion de las unidades.

Nuevo nodo: TileMapAltura:
	Dedicado para dibujar superficies que van por arriba de tilemapbase
Como se manejara la informacion:
	TileMapAltura tendra mayor prioridad que TileMapBase.
	Esto funciona con la logica de: Si se le define un valor a TileMapAltura es con la intencion de remplazar
	la funcionalidad de tilemapbase. Por lo tanto...
	Si TileMapAltura tiene un valor en ResistenciaMovimiento, Intransitable o TipoTerrenoID:
		El codigo priorizara el valor de TileMapAltura sobre el de base.
	Si TileMapAltura no tiene ningun valor asignado a dicha ubicacion, se selecciona el valor de TileMapBase.
